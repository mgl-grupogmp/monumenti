MONUMENTI BY JEMUTI — PUBLICACIÓN
Descomprime el ZIP fuera del directorio público. Copia el CONTENIDO de publicar/ a la raíz del dominio www.monumentibyjemuti.com, incluido .htaccess. Guarda antes una copia de la web y configuración anteriores. No mezcles la configuración de WordPress con la incluida. El paquete no requiere WordPress, compilación ni base de datos.
Servidor previsto: Apache con DirectoryIndex, mod_rewrite y permisos para .htaccess, HTTPS activo, PHP 8 y mail() configurado con un remitente autorizado del dominio. Activa la redirección de HTTP y del dominio sin www hacia https://www.monumentibyjemuti.com en el alojamiento. Si usas Nginx, configura index.html, PHP y las cuatro rutas antiguas según .htaccess (ambos sitemaps antiguos llevan al nuevo). Usa una raíz de publicación limpia para evitar servir scripts antiguos de WordPress.
Comprueba en el servidor que /consulta.php ejecuta PHP, que el formulario llega a info@monumentibyjemuti.com y que se puede responder al remitente. La aceptación por mail() no garantiza la entrega al buzón. El correo y el teléfono están visibles como alternativas. El limitador usa ficheros en el directorio temporal de PHP: aplica la limpieza periódica del sistema.
Proyectos: el caso Dior se publica con fecha 2024. Para Bvlgari 2026 y futuras colaboraciones utiliza la plantilla privada adjunta, reúne los datos y materiales aprobados y publica la ficha siguiendo la estructura de la de Dior. Añade enlace al índice y URL al sitemap. Los ficheros fuera de publicar/ son privados de edición.
Idiomas: los HTML en español tienen URL estables. Para la edición inglesa, crea /en/ con rutas equivalentes, traduce menús, metadatos, datos estructurados, textos alternativos, formularios y respuestas de PHP. Añade enlaces hreflang recíprocos y selector visible solo al publicar las traducciones. Cambia entonces las redirecciones temporales del inglés antiguo a sus destinos definitivos.
SEO y motores de respuesta: el contenido y enlaces están en el HTML, con URL canónicas, metadatos sociales y datos Schema.org. Envía /sitemap.xml a las herramientas de buscadores tras publicar. Revisa que el hosting y CDN permitan rastrear las páginas públicas.
Privacidad: confirma la adecuación del texto a los proveedores, transferencias y conservación reales del alojamiento y correo. La instalación no incluye servicios analíticos externos.
